Netwide Assembler 2.14 (2.16) Port to TRDOS 386 (& 386DOS) Operating System
(by help of Google AI)

is in progress...

Note: NASM 2.14 is the first proper version of NASM to assemble (the recent) TRDOS 386 v2.1 (or v2.0.11) Kernel without any errors or conflicts.
Older (than 2.14) versions of NASM are not proper to assemble TRDOS 386 v2.1 Kernel (due to some incompatible labels and methods in kernel source files).
This is the reason why I started to port NASM with its 2.14.02 version.
